One job title, 60 characters at most: the weirdest you can think of, and nothing else. A real-sounding senior title with one hilariously specific twist — apologizing to printers.

## The title

> Senior Vice President of Apologizing to Printers

## Run it

```sh
python3 main.py
```

The program writes the title to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
